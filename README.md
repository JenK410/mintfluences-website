# Mintfluences website

A static, responsive website for Mintfluences. Open this folder in VS Code and edit `index.html`.

## Preview

Open `index.html` in a browser, or use VS Code's Live Server extension for a local preview.

## Contact form

The consultation form opens the visitor's email app and prepares an inquiry to `hello@mintfluences.com`.

## Publish

This is a static site and needs a hosting target before `mintfluences.com` can be connected. Deploy the site to its hosting provider first, then use that provider's domain-specific DNS records in IONOS. Do not reuse records from another site; verification and routing records are unique to each site.
